# Scorpio App

A design-forward, responsive prototype for the **Scorpio smartphone ecosystem**.

## Included

- `index.html` — app screens and navigation
- `style.css` — complete visual design system
- `script.js` — screen navigation/interactions
- `assets/` — place for future logos, phone renders, icons, and other media

## Screens

1. Welcome
2. Home
3. Scorpio Phones
4. Scorpio Services
5. Scorpio Game Space
6. Profile

## Run locally

Open `index.html` in a browser.

For the best development experience, use VS Code + Live Server, or any simple static web server.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save and open the generated Pages URL.

## Customize

Edit the CSS variables at the top of `style.css` to change the Scorpio colors, spacing, radius, and overall theme.
